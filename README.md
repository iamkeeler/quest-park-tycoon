# Quest Park Tycoon

A Meta Quest 3 VR theme park simulator inspired by RollerCoaster Tycoon 1 (1999).
You don't watch your park from above — you *walk* it: build coasters with your
hands, grab guests, manage pricing, and ride what you built in first person.

- **PRD:** [PRD.md](https://github.com/iamkeeler/quest-park-tycoon/blob/main/PRD.md)
- **Engine:** Unity 2022 LTS + Meta XR SDK (**confirmed**)
- **Target:** Meta Quest 3, standalone, 72 Hz

## Project layout

```
Assets/_Project/Scripts/        runtime bootstrap, terrain, sim tick (all procedural — no hand-authored scenes)
Assets/_Project/Scripts/ParkSim/  guest / economy / park-rating stubs (Phase 1 fills these in)
Assets/_Project/Models/         FBX props generated by Assets/Blender/generate_assets.py
Assets/_Project/Shaders/        tiny vertex-color unlit shader for the spike
Assets/Blender/                 Blender script that procedurally builds the clay/diorama starter props
docs/SETUP.md                   Gary's exact on-machine checklist — start here
```

## Phase 0 exit criteria

1. Project opens in Unity 2022 LTS with no errors after installing the Meta XR packages.
2. Builds and boots on Quest 3 at a stable 72 Hz.
3. One grabbable cube (Meta XR Interaction SDK `Grabbable`).
4. Vertex-colored terrain tile grid renders.

## Quick start (full detail in `docs/SETUP.md`)

1. Install **Unity 2022.3 LTS** (latest patch) via Unity Hub, with the **Android Build Support** module.
2. Open this folder as a Unity project.
3. Add the Meta scoped registry (`https://npm.developer.meta.com`, scope `com.meta.xr.sdk`)
   and install `com.meta.xr.sdk.core` + `com.meta.xr.sdk.interaction`
   (or add them from the Unity Asset Store — Meta's recommended 2026 path).
4. `File > Build Settings > Android > Switch Platform`; enable **Oculus** under
   XR Plug-in Management; set IL2CPP + ARM64 (already in ProjectSettings).
5. Build & Run to the Quest 3 over USB.

## Package versions

`Packages/manifest.json` pins verified Meta XR SDK package names
(`com.meta.xr.sdk.core`, `com.meta.xr.sdk.interaction`,
`com.meta.xr.sdk.interaction.ovr`, `com.meta.xr.sdk.audio`) against the
`https://npm.developer.meta.com` registry. Version numbers are starting pins —
take the latest offered in Package Manager; the *names* and registry URL are
what was verified (Meta XR SDK v205+ era, 2026).
